# USB Power

- **Voltage** is what must match.
- **Current rating** is a maximum. The device draws only what it needs.
- **Ripple matters.** Noisy switch-mode chargers can cause problems, e.g. the sensor buzzing in [[Humidity Automation]].
- **Laptop USB ports** give cleaner power.
