# Instagram Profile Tools

Chrome extension for Instagram profile analysis.

## Overview
| | |
|---|---|
| **Tech** | Manifest V3, vanilla JS, no build step |
| **Billing** | Lemon Squeezy subscriptions: Free / Basic / Pro |
| **Differentiator** | Shows mean **vs** median engagement rate |
| **Sizzle reel** | Python / Pillow / NumPy / ffmpeg, 1080×1920, 29 s |

## Risks
| Risk | Note |
|---|---|
| Fail-open licence validation | Paid features may unlock if the licence check fails |
| Instagram ToS + data privacy | Exposure from the lead-extraction feature |
